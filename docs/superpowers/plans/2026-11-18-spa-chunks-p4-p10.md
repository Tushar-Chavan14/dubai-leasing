# SPA P4–P10 in small chunks

Each chunk is one superpowers plan (`superpowers:writing-plans`), written just before it runs so it matches the
code as built, then executed (`superpowers:executing-plans`) with one review at the end. A chunk leaves working,
tested software; the next chunk may start only when its "Needs" are done. Source: `docs/spa/task.md` (P4–P10), the
P3 review's deferred items, and `docs/spa/specs.md` §11 open questions. Ticks go to `docs/spa/task.md` as before.

Legend: **Needs** = chunks that must be done first. **Exit** = what proves it. **Confirm** = values or rules to
check with legal/compliance/business before or during the chunk (code fails closed until confirmed).
